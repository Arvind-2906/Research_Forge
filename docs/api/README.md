# API Documentation & Contracts

This directory contains endpoint definitions, request/response schemas, and inter-service API contracts for ResearchForge.

## Services
1. **Node.js Server API (`/api/v1`)**
   - Authentication (Better Auth)
   - Research Projects & Sessions
   - User History & Reports
2. **AI Engine API (`/api/v1`)**
   - Research Execution & Graph Triggers
   - Agent Status & Event Streaming (SSE)
   - Retrieval & Vector Ingestion
