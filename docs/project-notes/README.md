# Project Notes & Decision Records

This directory tracks Architecture Decision Records (ADRs), implementation notes, and sprint progress for ResearchForge.

## Key Decisions
- **ADR-001**: Independent 3-tier architecture (Next.js, Express, FastAPI).
- **ADR-002**: Prisma ORM as the single migration owner for Neon PostgreSQL and pgvector.
- **ADR-003**: LangGraph as the multi-agent state orchestration framework.
- **ADR-004**: Integration with existing remote MCP servers via official Python MCP client SDK.
